# Sprint 1 Log Parser

## Description
This script parses an auth log file and extracts failed SSH login attempts.

For each failed login attempt, the script extracts:
- timestamp
- source IP
- username

The script prints the results to the screen and also writes them to a CSV file.

## Files
- `logparser.py` - Python script for parsing failed SSH logins
- `sample-auth.log` - sample input log file
- `output.csv` - CSV output generated by the script
- `requirements.txt` - dependency file

## Requirements
- Python 3

No external Python packages are required.

## Usage
Run the script with:

```bash
python3 logparser.py sample-auth.log output.csv
